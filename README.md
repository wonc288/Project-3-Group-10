# 🟨 Food Nutrition & Exercise Tracker GUI

This repository contains a Java program that allows users to track their food intake and exercise routines. The program provides a simple GUI to select foods, view nutrition information, and track exercise routines.

## ✅ Requirements
- **Java (JDK)** version 11 or higher.
- The program uses **Swing** for the GUI, which is included in the JDK.

## 🧰 How to Install Java (If You Don’t Have It)
1. Go to [https://adoptium.net](https://adoptium.net)  
2. Download the **JDK installer** for your operating system (Windows, macOS, or Linux).  
3. Follow the installation instructions and restart your terminal/command prompt.  
4. Verify if Java is installed by running the following command in your terminal/command prompt:
    ```bash
    java -version
    ```
    You should see output similar to:
    ```
    openjdk version "17.0.10" 2024-01-16
    ```

## 🚀 How to Run the Program with GUI
Once Java is installed, follow the steps below to run the program.

### 🟢 Option 1: Run the Program Using the Command Line
1. **Download** the repository or copy the Java file `FoodNutritionGUI.java` to your local machine.
2. **Navigate to the directory** where the `FoodNutritionGUI.java` file is located in your terminal/command prompt.
3. **Compile the program**:
    ```bash
    javac FoodNutritionGUI.java
    ```
4. **Run the program**:
    ```bash
    java FoodNutritionGUI
    ```
